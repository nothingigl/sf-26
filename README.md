# Ferrari SF-26 (2026) — NFS Heat Interactive Garage

Интерактивный веб-шоурум болида **Scuderia Ferrari HP SF-26** (сезон Формулы-1 2026 года) в стилистике ночного неонового гаража *Need for Speed Heat*.

## Возможности
- 5 согласованных ракурсов осмотра (перетаскивание, стрелки `←`/`→`, клавиши `A`/`D` и панель миниатюр)
- Зум колесом мыши до 260% и свободное панорамирование деталей
- Интерактивные точки телеметрии (хотспоты) с проверенными ТТХ SF-26
- 3 режима освещения гаража: **Неон**, **Студия**, **Ночь**
- Режим **Авто-тур**, синтезированный синтвейв-фон (Web Audio API), панель полных ТТХ и фоторежим без HUD

## Запуск на GitHub Pages
1. Перейдите в **Settings → Pages** этого репозитория.
2. В разделе **Build and deployment** выберите `Deploy from a branch`, ветку `main` и папку `/ (root)`.
3. Нажмите **Save** — сайт откроется по адресу `https://nothingigl.github.io/SF-26/`.
